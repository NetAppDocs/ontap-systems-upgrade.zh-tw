您必須確保 node1 上的實體連接埠與 node3 上的實體連接埠正確對應。這樣，升級後 node3 才能與叢集中的其他節點以及網路進行通訊。

.開始之前
您應該已經從 _Hardware Universe_ 中獲取了新節點上的連接埠資訊。（前往 link:other-references.html["參考資料"] 以連結至 _Hardware Universe_）。您將在本節及 link:map_ports_node2_node4.html["將連接埠從節點2對應至節點4"] 中使用這些資訊。

node3 的軟體組態必須符合 node3 的實體連線能力，而且必須先還原網路連線能力，才能繼續升級。

.關於這項工作
連接埠設定可能有所不同、視節點的機型而定。
